# Security Policy

## Supported Versions

| Version | Supported          |
| :---    | :---               |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

Security and data integrity are taken seriously. If you discover a potential vulnerability or security issue:

1. **Do not create a public issue.**
2. Send an email to the repository owner or open a confidential security advisory on GitHub.
3. Include detailed reproduction steps, payload details, and browser/system environments.
4. You will receive an initial response within 48 hours.

## Local Development & Asset Security

- All external CDNs are loaded via HTTPS with standard resource integrity headers.
- The project does not collect, log, or persist private user data or credentials.
